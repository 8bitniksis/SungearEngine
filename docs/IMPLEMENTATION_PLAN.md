## 🎯 Обзор проекта

### Цель проекта

**Sungear Engine** — open-source (GPL-3.0) кроссплатформенный игровой движок
на C++23, разрабатываемый командой Pixelfield. Текущая версия — **0.14.0.8**.

### Ключевые компоненты

| Компонент | Технология | Статус | Где |
|-----------|------------|--------|-----|
| Ядро SGCore | C++23, EnTT, OpenGL 4.6 / GLES 3.2 | 🟡 Активная разработка | `Sources/SGCore/` |
| Точка входа | SGEntry | ✅ Работает | `Sources/SGEntry/` |
| Редактор v1 | Плагин, ImGui | 🟡 В разработке | `Plugins/SungearEngineEditor/` |
| Редактор v2 | Плагин | 🟡 В разработке | `Plugins/SungearEngineEditor-v2/` |
| Android-порт | GLES 3.2, NDK | ⚠️ Частично (без ввода) | `Sources/AndroidApp/` |
| Тесты | `Tests/Coro` | 🔴 Минимальные | `Tests/` |
| CI | — | ❌ Нет | — |
| Документация | docs/, Doxygen | 🟡 Заведена 2026-08-16 | `docs/` |

## 📊 Текущий статус

### Выполнено (✅ Done, по README)

- [x] **Ядро**: ECS, плагины, Serde (полиморфизм, шаринг данных), кодогенерация
  по мета-информации, параллельные физика и трансформации, октодерево,
  корутины и async-классы
- [x] **Рендер**: forward PBR (Cook-Torrance) для объектов/декалей/террейнов,
  тесселяция террейна с displacement, atmosphere scattering, стохастическая
  прозрачность, объёмный постпроцессинг, пикинг, дебаг-рендер, CSM, батчинг
- [x] **Ассеты**: SVG/TTF, JPG/PNG/DDS, импорт FBX/OBJ/GLTF (assimp),
  пакеты ассетов, сохранение/загрузка сцен
- [x] **Прочее**: 2D/3D-аудио (OpenAL), UI (XML + CSS), скелетные анимации
  с блендингом, ввод на ПК, Lua-скриптинг (sol2), навигация (recast),
  сеть (Boost.Asio)
- [x] **Платформы**: Windows, Linux; Android — частично
